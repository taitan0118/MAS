# MAS (Missing App Sales)

Phần mềm quản lý bán hàng cho cửa hàng nhỏ, tạp hóa. Bán hàng, kho, in bill, công nợ, thu chi, khuyến mãi, báo cáo Excel. Chạy được khi mất mạng.

**Dùng miễn phí cho cửa hàng của bạn. Không được bán, cho thuê, phân phối lại hay đổi tên đem bán.** © 2026 Nguyễn Tấn Tài (Missing).

## Tải về

Cách nhanh nhất: mở trang tải về https://taitan0118.github.io/MAS-tai-ve/ (trang tự nhận ra máy của bạn). Hoặc tải trực tiếp:

Vào mục **Releases** bên phải, mở bản mới nhất, tải file đúng với thiết bị:

| Thiết bị | File | Cách cài |
|---|---|---|
| Windows, máy POS Windows | `MAS-Windows.exe` | Bấm đúp, làm theo hướng dẫn. Nếu hiện "Windows đã bảo vệ PC của bạn": bấm **Thông tin thêm**, rồi **Vẫn chạy**. |
| Mac chip Apple (M1 trở lên) | `MAS-Mac-arm64.dmg` | Mở file, kéo MAS vào Ứng dụng. Lần đầu: bấm chuột phải vào MAS, chọn **Mở**, rồi **Mở** lần nữa. |
| Mac chip Intel (đời cũ) | `MAS-Mac-x64.dmg` | Cài như trên. Không chắc loại chip: bấm Apple, Giới thiệu về máy Mac này. |
| Android, máy POS Android | `MAS-Android.apk` | Mở file trên máy, cho phép **cài ứng dụng từ nguồn này** khi máy hỏi, rồi bấm Cài đặt. |
| iPhone, iPad | `MAS-iPhone.ipa` (cài bằng Sideloadly hoặc AltStore, hết hạn sau 7 ngày) hoặc cài nhanh bằng Safari | Mở đường dẫn web của MAS bằng Safari, bấm Chia sẻ, chọn **Thêm vào MH chính**. Xem file hướng dẫn cài đặt. |

## Lưu ý
- Dữ liệu lưu trên từng thiết bị, không tự đồng bộ. Vào **Cài đặt, Sao lưu ra file** thường xuyên.
- Các file cài chưa được ký số của nhà phát hành nên Windows và Mac sẽ hiện cảnh báo như trên. Đây là bình thường với phần mềm miễn phí cá nhân.
- Bản Android đóng gói chưa hỗ trợ in bill. Máy POS Android cần in bill nên cài bản web từ Chrome (xem hướng dẫn cài đặt).
